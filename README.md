# Flipdart-sales-analysis
Business Objective

The main goal of this project is to answer the following question:

How can a company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?

🛠 Tools & Technologies Used

Python – Data cleaning, transformation, and Exploratory Data Analysis (EDA)

SQL – Data extraction, aggregation, and querying

Power BI – Interactive dashboards and KPI visualization

GitHub – Version control and project documentation

🔄 Step-by-Step Workflow
Step 1: Data Collection

Collected sales and customer transaction data in CSV format.

Dataset includes information such as customer details, product categories, sales amount, discounts, payment methods, and purchase dates.

Step 2: Data Cleaning & Preparation (Python)

Handled missing values and duplicates

Converted data types where required

Treated outliers for numerical columns

Performed feature understanding and basic transformations

Libraries Used:

Pandas

NumPy

Matplotlib / Seaborn

Step 3: Exploratory Data Analysis (EDA)

Analyzed customer purchase behavior

Identified top-selling products and categories

Studied the impact of discounts and seasons on sales

Explored repeat purchases and customer loyalty trends

Step 4: Data Analysis Using SQL

Loaded cleaned data into MySQL

Wrote SQL queries using:

SELECT, WHERE, GROUP BY

JOIN, ORDER BY

Aggregations (SUM, COUNT, AVG)

Extracted insights related to:

Customer segments

Sales trends

Payment preferences

Repeat customers

Step 5: Data Visualization (Power BI)

Built an interactive dashboard including:

Sales KPIs (Total Sales, Average Order Value, Total Customers)

Category-wise and product-wise sales

Customer segmentation visuals

Monthly and seasonal sales trends

Enabled filters for better business understanding

📈 Key Insights

Certain product categories generate higher repeat purchases

Discounts significantly influence customer buying behavior

Online sales show faster growth compared to offline channels

A small group of loyal customers contributes a large portion of revenue

💡 Business Recommendations

Focus marketing efforts on high-value customer segments

Optimize discount strategies to improve profitability

Improve inventory planning based on seasonal demand

Strengthen customer retention programs

📌 Conclusion

This project demonstrates how data-driven analysis using Python, SQL, and Power BI can help businesses understand customer behavior and make informed strategic decisions.
